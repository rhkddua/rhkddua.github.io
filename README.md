# 회식 참여 여부 조사 웹앱

행정초등학교 6학년 선생님들의 회식 참여 여부를 조사하기 위한 웹앱입니다.

## 주요 기능

- 회원가입 및 로그인
- 닉네임, 비밀번호, 소속 선택
- 회식 날짜, 장소, 시간 확인
- 참석 / 다음 기회 선택
- 참석 시 음주 여부 선택
- 관리자 화면에서 응답 확인

## 배포

GitHub Pages를 사용하여 배포합니다.

## 파일 구조

- index.html
- styles.css
- app.js

## 참고

현재 버전은 localStorage 기반입니다.
여러 사용자의 응답을 실시간으로 공유하려면 Firebase Authentication과 Firestore 연결이 필요합니다.
